# 🌆 Ashwoq Portfolio 2D (V2 / V2.1)

This branch contains **intermediate versions (V2 & V2.1)** of my 2D portfolio — sitting between the initial **V1** and the more refined **V2.2 (latest)**.

---

## 🚧 About These Versions

These versions act as a **bridge between V1 and V2.2**.

They include some major upgrades compared to V1, but **don’t fully reflect the final polish and optimizations** present in V2.2.

Think of this as a **transition phase** — where I started experimenting with improvements but hadn’t completed them yet.
