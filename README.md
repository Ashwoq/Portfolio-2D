## 🚀 About This Version

This is the **V2 (updated version)** of my 2D portfolio.

Back on **Jan 1, 2025**, I shared the first version to kick off the year — and after a few (😅) months, I revisited it to improve the overall experience.

This is more of a **glow-up than a rebuild** ✨

---

## 🎨 What’s New in V2

- ✨ Added **depth effects** (shadows, insets, bloom) → still 2D, but feels slightly 3D
- 🎬 New **Rive loading screen** with animated logo & loading ball
- 🗜 Optimized assets (**PNG/JPEG → WebP**)
  - Reduced size: **~45MB → ~24MB**

- ⚡ Improved loading time: **~20s → ~12s**
- 👆 Better **touchscreen behavior** (reverse pedal autoplay, removed tooltips)
- 🎯 Updated **UI, transitions, and button animations**
- 🕷 A **Spider-Man references** 👀
