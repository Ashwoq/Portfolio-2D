# 🌆 Ashwoq Portfolio 2D (V1)

This repository contains **Version 1 (Beta)** of my 2D portfolio website, originally soft-launched on **January 1, 2025**.

---

## 🔗 Live Preview

👉 https://ashwoq2dv1.netlify.app/

---

## 🚀 About This Project

This is a **2D interactive portfolio website** that I built over several months as part of my learning and creative journey in web development.

* 🗓 **Initial Release (V1):** Jan 1, 2025 → [View V1](https://ashwoq2dv1.netlify.app/)
* 🆕 **Later Update (V2):** Around Nov 2025 → [View V2](https://ashwoq2d.netlify.app/)
* 📦 This repo contains the **original V1 version**

This was also shared on LinkedIn as a milestone to kickstart 2025.

---

## 🎨 Features

* 🌆 **60+ custom illustrations** (handmade)
* 🎞 **75+ unique CSS animations** (custom built)
* 🎨 Fully illustration-driven interactive environment
* 🧠 Scroll-based animations using GSAP
* 📦 ~4500+ lines of CSS
  *(yes... it's messy, yes... it can be reduced, no... I don't want to talk about it 😶‍🌫️)*
